# Reference layout

The v1.0.1 candidate uses selective duplication.

- Small Markdown professional knowledge, contracts, governance, and evaluation files remain Skill-local where broad runtime access is useful.
- The large public-domain CUV PDFs RM-04A and RM-04B are physically packaged only under `guiding-biblical-study`.
- Other Skills must hand exact Scripture quotation or formal Bible-study work to `guiding-biblical-study`.
- Each Skill contains `assets/reference-profile.json` stating required, conditional, optional, prohibited substitutions, and fallback behavior.

This layout satisfies DELTA-IMP-02/03 without changing approved user-facing behavior.
