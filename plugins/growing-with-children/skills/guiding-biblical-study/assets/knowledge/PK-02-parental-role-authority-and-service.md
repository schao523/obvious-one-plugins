# PK-02 — Parental Role, Authority, and Service

## Purpose
幫助 Plugin 協助父母分辨「父母權威」與「控制」的差別，並把父母角色理解為帶有責任、服務、保護與引導目的的角色。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 引言、第四章「你是主管」、第十三章摘要
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Core principles
1. 父母角色包含真實責任，因此也包含適齡、適度的帶領與界線。
2. 父母權威不是為了父母個人的方便、面子、控制慾或情緒發洩。
3. 有效的父母角色應同時包含領導與服務：目標是孩子的益處與成熟，而不是讓孩子成為父母意志的延伸。
4. 權威應被用來保護、教導、建立責任與幫助孩子逐步形成自我管理能力。
5. 父母的管教若演變成敵對、報復、羞辱或情緒發洩，就偏離了教養目的。
6. correction 的目標應是恢復、成長與責任，而非讓父母「贏」。
7. 隨著孩子成熟，父母的直接權威應逐步轉化為更多 influence、dialogue、shared reasoning 與 mutuality。

## When to consult
- 父母問「孩子是不是一定要聽我的？」
- 家庭規則與界線
- 管教、責任、後果
- 父母與孩子權力衝突
- 青少年自主
- 成年子女
- 敏感議題中的 parental responsibility

## Application guidance
Plugin 應先幫助父母分辨：
1. 這件事屬於安全／責任範圍，還是只是偏好差異？
2. 孩子的年齡與成熟度如何影響父母應介入的程度？
3. 父母現在是在保護／教導，還是在試圖控制？
4. 是否能用更少 coercion、更多 explanation / influence 的方式達成合理目的？
5. 後果是否與行為、年齡、責任程度相稱？

## Parent self-check
- 如果孩子不同意我，我最害怕的是什麼？
- 我現在要求的是孩子真正需要的，還是我自己的方便？
- 我的語氣是在引導，還是在報復？
- 我是否把「尊重父母」等同於「永遠不能提出問題」？
- 這個要求是否有清楚目的？

## Boundaries
- 本檔不授權暴力、羞辱、虐待或以怒氣發洩為目的的處置。
- 書中關於體罰的具體主張不在本檔轉化為 Plugin 的一般政策；具體身體管教議題必須受現代安全、法律與平台政策約束。
- 成年子女情境不可沿用兒童式直接管教邏輯。
- 高風險安全事件由 Safety / Escalation Policy 優先。
