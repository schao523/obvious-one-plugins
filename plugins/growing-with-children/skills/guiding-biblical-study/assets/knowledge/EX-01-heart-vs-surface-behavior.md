# EX-01 — Heart vs. Surface Behavior

## Purpose
示範 Plugin 如何從「孩子做了什麼」進一步探索「孩子為什麼這樣做」，避免只停在表面行為修正。

## Pattern type
Generalized example pattern; not copied from source stories.

## Trigger
父母描述：
- 孩子搶東西、說謊、發脾氣、推卸責任、欺負手足；
- 同一類行為反覆發生；
- 父母表示「講很多次都沒用」。

## Poor pattern
1. 立刻貼標籤：「你就是自私／懶惰／不誠實。」
2. 只問「你為什麼不聽話？」
3. 直接給處罰。
4. 不再了解動機與情境。

## Better pattern
### Step 1 — Describe
「剛才你把弟弟的東西拿走，他說不要，你還是拿了。」

### Step 2 — Explore
「你當時最想要的是什麼？」

### Step 3 — Clarify meaning
「你覺得如果現在拿不到，會怎麼樣？」

### Step 4 — Identify deeper issue
可能涉及：
- 想控制；
- 害怕失去；
- 比較；
- 急著滿足自己；
- 報復；
- 被忽略感。

不要由 Plugin 替孩子確定動機，只能提出可能性並邀請確認。

### Step 5 — Connect to character / faith
「這件事讓我們看到，你現在很難在自己想要的東西和別人的需要之間做平衡。」

### Step 6 — Next action
「你現在可以怎樣修復？下次可以怎樣做？」

## Parent-coaching version
Plugin 可先問父母：
- 「你現在看到的是什麼行為？」
- 「你對孩子動機的看法，有哪些是事實、哪些是推測？」
- 「如果這個模式再出現，你希望孩子學會什麼，而不只是停止什麼？」

## Life-stage adaptation
- 幼兒：問題簡單、具體。
- 兒童：加入責任與他人影響。
- 青少年：可以討論價值、選擇與後果。
- 成年子女：不採 child-discipline posture；改用 adult-to-adult reflection。

## Boundaries

- 不把推測當事實。
- 不把一次錯誤變成人格定論。
