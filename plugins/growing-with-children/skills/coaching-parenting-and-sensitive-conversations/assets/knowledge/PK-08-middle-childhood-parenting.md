# PK-08 — Middle Childhood Parenting

## Purpose
幫助 Plugin 在兒童期把教養焦點從單純「有沒有服從」逐步轉向品格、良知、智慧、責任與對行為原因的理解。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 第十六章「兒童期：訓練目標」、第十七章「兒童期：訓練程序」
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Source-supported developmental shift
原書清楚描述一個焦點轉變：較年幼階段較重視基本順服；進入兒童期後，父母不能只問「有沒有違抗」，而需要處理更廣泛的品格問題。孩子即使沒有直接違抗父母，也可能表現自私、嘲笑、冷漠、懶散或缺乏體恤。這一階段因此更適合發展內在判斷與良知。

## Core principles
1. 教養目標從單純 compliance 擴展到 character formation。
2. 品格包括可靠、誠實、恩慈、體恤、助人、勤勉、忠心、謙卑、節制等面向。
3. 孩子不可能永遠在父母視線下，因此需要形成能在父母不在場時仍作判斷的內在準則。
4. 父母需要區分：
   - 行為本身；
   - 行為背後的原因；
   - 長期形成的模式。
5. 不應只給孩子一個容易守住的最低標準，然後把「沒有違規」等同於成熟。
6. 父母可藉事件協助孩子辨識「這樣做反映了什麼樣的人正在形成」。
7. correction 應逐步增加 reasoning：孩子不只是知道「不能做」，也能理解「為什麼」。

## When to consult
- 小學年齡兒童
- 自私、嘲笑、懶散、不負責任
- 孩子表面守規矩但品格仍有問題
- 家務、承諾、誠實、同理心
- 需要培養自主判斷
- 父母說「他沒有違規，但就是態度不好」

## Character coaching process
1. **Describe**：先描述具體行為，不貼人格標籤。
2. **Explore**：問孩子當時在想什麼、想得到什麼。
3. **Name the character issue**：例如責任、誠實、體恤、勤勉。
4. **Consider impact**：這個選擇如何影響別人？
5. **Identify better response**：下次可以怎樣做？
6. **Practice**：給孩子可執行的小責任。
7. **Review**：之後回顧，而不是一次談完就結束。

## Application guidance
- 多用具體生活事件做品格反思。
- 不把「態度不好」當作足夠診斷，需說明可觀察行為。
- 將 responsibility 與 competence 一起提升：責任增加時，也給予必要教導與練習。
- 適度讓孩子承擔合理後果，並協助他理解後果與選擇的關係。
- 對孩子提出問題時，仍需適齡，避免成人式抽象審問。

## Boundaries
- 品格語言不可變成羞辱性標籤，如「你就是自私的人」。
- 不把一次失誤等同固定人格。
- 不忽略神經發展、學習困難或其他可能影響行為的因素；本檔不做診斷。
- 高風險問題轉 Safety / Escalation Policy。
