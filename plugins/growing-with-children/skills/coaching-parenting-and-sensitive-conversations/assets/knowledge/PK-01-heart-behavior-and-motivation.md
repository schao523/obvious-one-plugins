# PK-01 — Heart, Behavior, and Motivation

## Purpose
幫助 Plugin 在面對孩子的行為問題時，不只處理表面行為，而能進一步協助父母辨識行為背後可能的動機、渴望、目標、恐懼與信仰取向。

- Source: 《子女心、父母情》

## Core principles
1. 外在行為通常不是完整問題本身，而是內在狀態的表現。
2. 父母需要從「發生了什麼」繼續追問「孩子為什麼這樣反應」。
3. 不要把所有問題簡化成服從／不服從；應留意孩子正在追求什麼、害怕什麼、保護什麼或渴望什麼。
4. 教養目標不是只把不可接受的行為換成可接受行為，而是幫助孩子理解自己並形成更成熟的內在取向。
5. 父母應邀請孩子參與理解自己的過程，而不是只對孩子下結論。
6. 重複出現的行為通常值得重新檢視其背後的動機、家庭互動、期待與信仰因素。
7. 對孩子的解讀必須保持謙卑；Plugin 不應把推測的動機當成確定事實。

## When to consult
在下列情況應優先查閱：
- 重複性行為問題；
- 說謊、發怒、嫉妒、自私、衝突、逃避責任等；
- 父母表示「講很多次都沒用」；
- 父母只聚焦於處罰、獎勵或立即服從；
- 需要從 Coach / Consultant 進一步理解 deeper concern。

## Suggested diagnostic questions
Plugin 可協助父母思考：
- 這個行為發生前，孩子最想得到或避免的是什麼？
- 孩子可能如何理解當時的情境？
- 這件事牽涉的是控制、害怕、被接納、比較、方便、報復、面子，還是其他需要？
- 這種行為是否在不同情境重複出現？
- 父母自己的期待或反應是否也在強化這個模式？
- 我們目前知道的是事實，還是只是在猜孩子的動機？

## Application guidance
- 先描述可觀察事實，再探索可能原因。
- 使用開放式問題，不替孩子宣告內在動機。
- 將行為處理與關係、品格、責任、信仰反思連結。
- 若資訊不足，先提出一個關鍵問題並等待。
- 若使用者只要快速建議，可提供暫時性行動，但標明 deeper cause 尚未釐清。

## Boundaries
- 不做心理診斷。
- 不把所有困難都解釋成單一屬靈原因。
- 不以羞辱、貼標籤或武斷語氣描述孩子的心。
- 不把本檔作為危機處理或安全評估依據。
- 涉及即時危險、虐待、自傷等情況時，交由 Safety / Escalation Policy 優先處理。
