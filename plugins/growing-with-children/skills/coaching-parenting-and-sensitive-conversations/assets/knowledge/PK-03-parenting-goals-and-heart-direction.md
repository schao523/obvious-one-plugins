# PK-03 — Parenting Goals and Heart Direction

## Purpose
幫助 Plugin 協助父母檢查教養目標，避免把成績、表現、乖巧、社會成功、父母面子或方便，默認為教養的最高目標。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 第五章「檢驗目標」、第六章「再思目標」、第十三章摘要
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Core principles
1. 所有教養方式背後都有目標，即使父母沒有明說。
2. 父母需要辨識自己真正用什麼標準定義「成功的孩子」。
3. 外在成就可以有價值，但不應取代品格、智慧、責任、愛神愛人與成熟生命。
4. 文化常把競爭、表現、自我價值、物質、能力或社會認可變成默認目標；父母需要有意識地檢驗。
5. 父母的生活本身就是一種塑造力量；孩子會從父母如何使用時間、金錢、讚賞、焦慮與比較，學到家庭真正重視什麼。
6. 教養目標需要和方法一致；不能一方面說重視生命與信仰，一方面只在成績或表現下降時才高度介入。
7. 父母需要分辨短期目標與長期目標，並評估目前策略是否真的服務長期成熟。

## When to consult
- 學業、競賽、才藝、升學
- 「我只希望他成功」
- 品格培養
- 習慣與目標設定
- 父母過度焦慮
- 孩子表現與家庭關係緊張
- Parent Reflection 模式

## Goal clarification prompts
Plugin 可引導父母回答：
- 如果孩子問「爸爸媽媽最希望我成為什麼樣的人？」你希望答案是什麼？
- 你現在最焦慮的是孩子的生命狀態，還是孩子的表現？
- 你最常稱讚孩子的是什麼？
- 你的家庭時間分配透露了哪些真正優先次序？
- 目前這個要求是短期方便，還是長期成熟需要？
- 你希望孩子十年後因這件事學會什麼？

## Application guidance
- 先辨識父母目前的顯性目標與隱性目標。
- 區分「合理次級目標」與「不能成為終極目標的東西」。
- 幫助父母把行動重新連回品格、責任、關係與信仰。
- 若父母目標與孩子生命階段不匹配，交由 IM-08 進一步調整。

## Boundaries
- 不否定學業、技能、運動或成就本身的價值。
- 不把任何單一外在成就自動視為屬靈失敗。
- 不以罪咎操控父母。
- 不從本書的具體文化批判自動推論今日每個家庭情境。
