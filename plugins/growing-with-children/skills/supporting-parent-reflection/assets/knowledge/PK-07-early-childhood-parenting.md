# PK-07 — Early Childhood Parenting

## Purpose
幫助 Plugin 在嬰幼兒與學齡前階段，依孩子尚未成熟的理解力、自我控制與責任能力，提供較清楚、具結構、可重複的父母帶領方式。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 第十四章「嬰幼兒期：訓練目標」、第十五章「嬰幼兒期：訓練程序」
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Source-supported developmental emphasis
原書把嬰幼兒期視為一個需要清楚父母帶領與權威結構的階段。孩子尚未具有成熟的判斷、自我管理與長期思考能力，因此父母需要提供清楚且一致的引導，而不能把成人式的自主責任提前交給幼兒。

## Core principles
1. 幼兒需要簡單、清楚、可理解的家庭界線。
2. 指令應符合年齡與能力，避免一次要求過多。
3. 父母需要一致，而不是依情緒忽嚴忽鬆。
4. 目標不只是「立刻停止行為」，而是逐步建立可預期的秩序、責任感與信任。
5. 年幼孩子需要大量重複、示範與陪伴，不能假設一次說明就能內化。
6. 教養要求必須符合孩子實際發展程度。
7. 父母應把自己的權威理解為照顧、保護、教導與服務，而不是支配。
8. 外在行為問題仍可逐步連回「心／動機」，但對幼兒的反思要求應非常簡單，不可使用超出其認知能力的抽象問題。

## When to consult
- 嬰幼兒、學齡前孩子
- 不服從、日常規律、生活習慣
- 睡眠、收拾、吃飯、等待、分享等結構性問題
- 父母不知道該給多少自由
- 父母對孩子提出超齡要求

## Application guidance
### Prefer
- 一次一個清楚要求
- 短句
- 可觀察的行動
- 重複示範
- 穩定 routine
- 立即而平靜的回應
- 簡單選擇而不是開放式無限選項
- 事後簡短說明「為什麼」

### Avoid
- 長篇說教
- 要幼兒進行成人式自我分析
- 因孩子能力不足而解讀成惡意
- 父母在生氣時臨時增加規則
- 用羞辱或恐嚇換取服從

## Life-stage adaptation rule
對幼兒，父母的 direct guidance 比例較高；但 direct guidance 仍應與愛、理解、清楚說明及穩定關係並行。

隨孩子成熟，Plugin 應逐步把更多空間交給理解、選擇、責任與自我管理，而不是固定停留在幼兒式控制。

## Boundaries
- 原書在此階段包含具體體罰主張；本 knowledge asset **不將這些主張轉換為 Plugin 的一般行為政策**。
- 不提供造成傷害、羞辱、恐懼或虐待的處置。
- 身體安全、發展遲緩、嚴重行為或醫療問題，不由本檔診斷。
- Safety / Escalation Policy 在高風險事件中優先。
