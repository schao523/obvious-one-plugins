# PK-04 — Biblical Parent–Child Communication

## Purpose
幫助 Plugin 把親子溝通理解為持續、雙向、多形式的關係實踐，而不是只有「規定—糾正—處罰」。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 第八章「溝通」、第九章「溝通的形式」、第十章「溝通的生活」
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Core principles
1. 親子溝通不是父母單向輸出，而是雙向互動。
2. 父母需要能幫助孩子表達思想、感受與內在困惑。
3. 溝通不應只在問題爆發時發生；平常累積的關係品質決定危機時是否談得下去。
4. 溝通形式應依情境調整，不可所有問題都只用責備或命令。
5. 可使用的溝通功能包括：鼓勵、糾正、責備、懇勸、警告、教導與禱告等；不同情況需要不同形式。
6. 使用錯誤的溝通形式會傷害關係，例如孩子需要引導時卻受到嚴厲責備。
7. 溝通的目的不只是讓孩子知道父母的立場，也包括父母真正認識孩子。
8. 有效的溝通需要時間、耐心、彈性與生活中的持續投入。

## Communication-selection guide
Plugin 可依情境協助父母選擇：
- **Encourage**：孩子灰心、努力但受挫。
- **Guide / Teach**：孩子不知道怎麼做。
- **Correct**：孩子需要看見錯誤與更好的方向。
- **Warn**：風險清楚且需要預防。
- **Appeal**：議題重大、需要認真邀請孩子思考。
- **Pray / Reflect spiritually**：適合家庭信仰情境且孩子願意參與。
- **Listen first**：資訊不足、情緒高、孩子正嘗試表達。

## When to consult
- 親子衝突
- 「孩子不跟我說話」
- 家庭規則與糾正
- 青少年對話
- 敏感議題
- 家庭靈修
- 父母需要實際對話句型

## Application guidance
- 先判斷需要哪一種溝通功能，而不是預設「糾正」。
- 對話前先看孩子是否有能力與情緒空間參與。
- 一次處理一個主要目標。
- 問題不清楚時先聽，不急著教訓。
- 若需要直接給建議，保持簡潔，並保留後續對話入口。

## Boundaries
- 禱告不能取代必要的安全、醫療、法律或心理專業處置。
- 聖經教導不能成為羞辱或壓制孩子表達的工具。
- 「多形式溝通」不表示每次對話都要使用所有形式。
- 敏感議題中若孩子尚未被理解，優先使用 listening / clarification。
