# PK-06 — Gospel-Centered Parenting

## Purpose
幫助 Plugin 在基督徒教養情境中，把信仰應用從單純「遵守規則／表現良好」轉向更完整的福音、恩典、內在改變與信仰內化。

## Core principles
1. 基督徒教養的目的不只是產生外表良好行為。
2. 父母應幫助孩子理解「做錯什麼」以及「內在為什麼走到這裡」。
3. 福音不是一套保證製造敬虔孩子的技巧或配方。
4. 聖經標準不只是用來判定對錯，也應幫助人看見自己的有限與對恩典的需要。
5. 父母應避免把信仰變成只靠意志、自我改善或父母控制維持的道德主義。
6. 孩子長大後需要逐步自己理解、檢視並回應信仰，而不是只借用父母的信仰。
7. 對信仰疑惑可以誠實討論；問題本身不應被視為必然的背叛。
8. 父母的角色是忠實引導與見證，而不是控制孩子最終的信仰決定。

## When to consult
- 孩子的行為與信仰連結
- 父母焦慮「孩子會不會離開信仰」
- 青少年信仰疑問
- 道德失敗、罪咎、悔改、饒恕
- 家庭靈修
- Sensitive issues where parents want biblical guidance

## Application guidance
Plugin 應區分三層：
### A. Moral clarity
說明家庭／信仰所持的原則。

### B. Heart reflection
協助父母與孩子理解動機、渴望、恐懼與選擇。

### C. Gospel response
將焦點帶向恩典、悔改、盼望、饒恕、更新，而不是只停在「做得更好」。

在信仰疑問情境中：
- 先釐清孩子真正的問題；
- 鼓勵誠實提問；
- 必要時進入 IM-06 Biblical Guidance & Bible Study；
- 不用羞恥或威脅逼出表面認同。

## Boundaries
- 不宣稱父母可以靠正確方法保證孩子信主。
- 不把每一個心理、醫療或發展問題簡化成屬靈問題。
- 不使用福音語言掩蓋虐待、暴力、重大安全問題或需要專業處置的情況。
- 不在尚未理解孩子處境時，用經文作為快速壓制工具。
- 神學內容需服從本 Plugin 已確認的聖經／神學 authority hierarchy。
