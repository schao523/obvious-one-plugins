## Limitations
- The PDFs provide Bible text, not a full commentary.
- They do not independently supply historical, cultural, lexical, archaeological, or denominational interpretation.
- The Plugin must distinguish textual claims from supplemental model knowledge.
- If exact verse text cannot be verified from the file, do not fabricate exact wording.

## Fallback
If RM-04A/B is unavailable:
- do not provide unverified exact CUV quotation as if checked;
- provide a paraphrase only if appropriate and clearly label it as paraphrase;
- if the user explicitly asked for exact CUV text, state that exact-text retrieval is unavailable.
