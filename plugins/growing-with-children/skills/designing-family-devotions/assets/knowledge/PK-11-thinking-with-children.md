# PK-11 — Thinking with Children

## Purpose
幫助 Plugin 協助父母把孩子視為正在發展中的思考者，透過提問、理由、澄清、反例與共同探索，培養孩子清楚而負責任的思考，而不是只把答案告訴孩子。

## Source basis
- Source: Scott Hershovitz, *Nasty, Brutish, and Short*
- Primary basis: Conclusion / “How to Raise a Philosopher” and related methodological passages
- Source role: Professional Dialogue & Critical-Thinking Reference
- Authority level: Supporting reasoning reference; not theological authority
- Use mode: Advisory, substantially transformed
- Runtime dependency on original PDF: No

## Core principles
1. 父母除了支持孩子的興趣，也可以有意識地支持孩子成為更好的 thinker。
2. 最簡單的方法不是講授哲學，而是提出問題，並對孩子的答案繼續追問。
3. 好的思考不是只要求孩子「有意見」，而是鼓勵他說明理由。
4. 孩子的想法應被認真對待，即使父母不同意、覺得幼稚或尚未成熟。
5. 對話的目標不是父母用辯論能力壓倒孩子，而是讓雙方更理解問題。
6. 父母可以幫助孩子檢驗自己的觀點，而不只檢查別人的觀點。
7. 父母不需要總是知道答案；共同思考本身可以有價值。
8. 「with the child」比「for the child」更能培養思考責任。

## Reusable questioning moves
Plugin 可生成類似以下功能的問題，但不需固定逐字使用：
- 你目前怎麼看這件事？
- 你為什麼這樣想？
- 你所說的這個詞，對你是什麼意思？
- 有沒有什麼情況會讓你改變看法？
- 如果有人不同意，他可能有什麼理由？
- 你的想法有哪些地方還不確定？
- 我們需要查什麼資料才能想得更清楚？

## Thinking-with-child sequence
1. **Elicit** — 先讓孩子提出自己的看法。
2. **Clarify** — 澄清概念與用詞。
3. **Ask for reasons** — 了解理由與假設。
4. **Test** — 探索反例、例外或其他觀點。
5. **Perspective shift** — 看另一方可能怎麼理解。
6. **Synthesize** — 暫時整理目前較合理的理解。
7. **Leave room** — 必要時保留未解問題，之後再談。

## When to consult
- 孩子問「為什麼」
- 價值觀或道德問題
- 公平、權利、規則、責任
- 信仰問題需要先釐清思想
- 親子意見不同
- Sensitive issue 但沒有立即安全危機
- 父母容易直接給答案或說教

## Life-stage adaptation
- 幼兒：問題簡短、具體，以例子為主。
- 兒童：可以比較理由、後果與不同觀點。
- 青少年：可進一步討論假設、價值衝突、反例與證據。
- 成年子女：採 adult-to-adult dialogue，不以「教學」姿態預設父母是唯一答案來源。

## Application guidance
- 一次不要丟出太多追問。
- 孩子卡住時可以提供提示，不必故意讓對話變成考試。
- 如果孩子只是需要安慰，不要硬把情緒時刻哲學化。
- 若父母已經有清楚立場，可在理解孩子後分享理由，而不是假裝中立。
- 目標是理解與思考品質，不是「辯贏」。

## Boundaries
- 本檔不是價值中立或神學權威。
- 不能用 Socratic questioning 取代必要的安全決策。
- 不把所有親子對話變成辯論。
- 不利用成人知識優勢羞辱、設陷阱或「問到孩子沒話說」。
- 若問題需要專業事實、醫療、法律或心理資訊，需另用適當來源。
