# PK-09 — Adolescent Parenting

## Purpose
幫助 Plugin 在青少年階段把父母角色從主要依靠直接權威，逐步轉向 influence、counsel、relationship、reasoning、faith internalization 與預備成年自主。

## Source basis
- Source: 《子女心、父母情》
- Primary basis: 第十八章「青少年期：訓練目標」、第十九章「青少年期：訓練程序」
- Source role: Primary Professional Parenting Knowledge Authority
- Use mode: Advisory, transformed knowledge
- Runtime dependency on original PDF: No

## Source-supported developmental shift
原書將青少年描述為逐步走向獨立、形成價值判斷並重新檢視既有信念的階段。此時父母若只依賴強制權威，容易增加疏離；更重要的是建立影響力、可信任的引導關係與能夠討論重大問題的家庭環境。

## Core principles
1. 青少年正在形成自己的價值判斷，父母需要從「替他決定」逐步轉向「幫助他學會判斷」。
2. 長期影響力比單純外在強制更重要。
3. 父母的 correction 不應帶有人格羞辱。
4. 青少年需要一個能被愛、被理解、被鼓勵並接受引導的家庭環境。
5. 青少年開始面對同儕、文化與其他思想對家庭信念的挑戰，父母需要能討論，而不是只封鎖問題。
6. 信仰逐步從「父母教我的」走向「我自己是否相信」；父母不能替孩子完成內化。
7. 父母可以透過分享自己的掙扎與學習，降低居高臨下感，增加真實對話。
8. 若過去親子關係受損，沒有捷徑重新取得影響力；父母可能需要先承認自己的錯誤、修復關係並重新建立信任。
9. 青少年要求獨立不應一律被當成反叛；需要分辨哪些是正常成熟、哪些涉及責任或安全。

## Three source-derived developmental concerns
原書以三個「生命基石」組織青少年目標：
- 敬畏神／形成自己的信仰責任；
- 保留父母作為智慧與訓誨來源的關係；
- 面對不良同儕與誘惑時能作出分辨。

Plugin 應把這些轉化成更一般的行為目標：
- faith ownership；
- trusted parental influence；
- discernment under peer/cultural pressure。

## When to consult
- 青少年要求更多自主
- 親子衝突與疏離
- 價值觀不同
- 同儕壓力
- 信仰疑惑
- 敏感 disclosure
- 戀愛、網路、社交、責任等需要 judgment 的議題
- 父母想用更強控制解決問題

## Adolescent guidance sequence
1. **Clarify the issue**：是安全、責任、價值、偏好，還是信仰？
2. **Listen**：讓青少年陳述看法與理由。
3. **Assess responsibility**：父母目前仍需承擔哪些實際責任？
4. **Use influence**：以理由、經驗、關係與信仰原則引導。
5. **Set boundary if needed**：若涉及未成年人的安全或家庭責任，界線應清楚且可說明。
6. **Allow ownership**：在可承擔範圍內讓青少年作選擇並學習後果。
7. **Keep dialogue open**：不要要求一次談話解決全部問題。

## Sensitive-issue adaptation
對敏感議題，優先：
- 不立即羞辱或貼標籤；
- 先理解「孩子實際在說什麼」；
- 區分理解與認同；
- 避免在震驚情緒中進行全面教訓；
- 必要時分多次談；
- 若安全風險出現，切換 Safety / Escalation Policy。

## Boundaries
- 不把正常增加的自主需求自動視為罪、病態或反叛。
- 不以關係威脅迫使表面認同。
- 不宣稱父母可以控制孩子最終信仰選擇。
- 不用「父母權威」合理化羞辱、強迫或虐待。
- 本檔不取代心理、醫療、法律或危機專業。
