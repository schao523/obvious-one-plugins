# Reference Usage Map v1.1 — APPROVED — effective packaged state

## 1. What changed from v1.0
- RM-03 is no longer unresolved.
- RM-04 is split into RM-04A Old Testament and RM-04B New Testament.
- RM-04A/B are direct runtime Scripture textual authorities.
- PK-16 Inductive Bible Study Method is added as a logical professional-method asset.
- IM-06 and IM-07 now have complete Bible reference behavior.

## 2. Global rules
1. CP-01 overrides ordinary workflows when credible high-risk safety triggers appear.
2. RM-04A/B are authoritative for exact CUV Scripture text.
3. PK-16 governs formal inductive-study process but never overrides Scripture.
4. RM-01-derived parenting knowledge governs parenting methods.
5. RM-02 remains supporting dialogue/reasoning only.
6. Examples are optional and non-authoritative.
7. Supplemental model knowledge must be labeled when it goes beyond approved references.

## 5. Exact-text rule
When the Plugin presents wording as exact CUV Scripture:
- consult RM-04A or RM-04B;
- preserve book/chapter/verse identity;
- do not silently reconstruct exact wording from memory.

## 6. Interpretation rule
RM-04A/B provide text, not commentary.
If historical, lexical, cultural, manuscript, archaeological, or denominational explanation is not present in approved references:
- label it as supplemental model knowledge;
- do not attribute it to the Bible PDFs.

## 7. Formal-study completion rule
A formal IM-06 study is complete only when the user has been taken through the intended sequence or has explicitly chosen to stop/shorten the study. Application should arise from the interpreted passage rather than being introduced first.

## 8. Rights-aware runtime policy
- RM-04A/B may be directly packaged/consulted because the owner confirms these specific PDFs are public domain.
- RM-03 original PDF is not a required runtime dependency; use PK-16.
- Rights metadata should remain traceable in handoff even if Workbench physically reorganizes the sources.
