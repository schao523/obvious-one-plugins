# EX-09 — Sensitive-Issue Conversation Patterns

## Purpose
提供數種通用敏感議題對話模式，讓 Plugin 能套用 PK-15，而不是為每一個敏感主題建立獨立 mini-guide。

## Pattern A — Unexpected Disclosure

### Trigger
孩子突然透露一件讓父母震驚的事。

### Sequence
1. **Receive** — 「謝謝你願意告訴我。」
2. **Regulate** — 父母先避免立即威脅、羞辱或全面說教。
3. **Safety check** — 確認是否有立即危險、虐待、脅迫、自傷等。
4. **Clarify** — 「你希望我現在先聽，還是一起想辦法？」
5. **Understand** — 了解事情的實際內容與孩子的需要。
6. **Next step** — 決定今天只需要做到哪一步。

### Success
不是「孩子立刻同意父母」，而是：
- 安全被確認；
- 對話沒有關門；
- 父母理解得更準；
- 有下一步。

## Pattern B — Serious Moral / Value Disagreement

### Trigger
孩子與父母在重大價值、信仰或生活選擇上不同。

### Sequence
1. Ask child to explain.
2. Distinguish understanding from agreement.
3. State parental conviction clearly but calmly.
4. Identify real parental responsibility.
5. Set boundary only where responsibility/shared obligation justifies it.
6. Preserve ongoing dialogue.

### Sample functional language
「我可能不會同意你的結論，但我希望先正確理解你。」

---

## Pattern C — Serious Mistake

### Trigger
孩子做了重大錯誤決定。

### Sequence
1. Safety first.
2. Establish facts.
3. Clarify responsibility.
4. Explore motivation without mind-reading.
5. Determine consequence / repair.
6. Identify restoration path.
7. Follow up later.

### Avoid
- humiliation;
- permanent labels;
- punishment with no learning/restoration purpose.

---

## Pattern D — Child Refuses to Talk

### Trigger
孩子說：
- 「我不想講。」
- 「你不要問了。」

### Sequence
1. Assess whether safety requires immediate clarification.
2. If no safety urgency, respect pause.
3. Communicate availability:
   「你現在不想談可以，我想讓你知道之後你願意時我會聽。」
4. Avoid repeated interrogation.
5. Revisit later if appropriate.

### Boundary
If there is credible danger, the parent may still need to ask minimum safety-critical questions.

---

## Pattern E — Parent Too Emotionally Activated

### Trigger
父母感到：
- 震驚；
- 憤怒；
- 羞恥；
- 恐慌；
- 想立刻做出重大決定。

### Sequence
1. Do not conduct the full conversation while dysregulated.
2. Say enough to preserve safety and relationship.
3. Take time to regulate.
4. Return at an agreed time.
5. Then clarify and respond.

### Sample functional language
「我很在乎這件事，也需要一點時間讓自己能好好跟你談。我不是不要談，我們晚一點繼續。」

## Pattern F — Parent Wants Biblical Guidance Immediately

### Trigger
父母想第一時間引用聖經解決敏感議題。

### Sequence
1. Clarify actual situation first.
2. Identify relevant biblical question.
3. Distinguish Scripture from parental fear/preferences.
4. Enter IM-06 only when the issue is sufficiently understood.
5. Return to relational next step.

---

## Pattern G — Adult Child Sensitive Disclosure

### Trigger
成年子女分享重大生活／價值／身份議題。

### Sequence
1. Adult-to-adult listening.
2. Ask permission before unsolicited advice when appropriate.
3. State convictions honestly.
4. Do not revert to child-discipline logic.
5. Preserve relationship and real boundaries.

---

## Pattern H — Safety Overrides Ordinary Dialogue

### Trigger
Credible immediate danger, abuse, coercion, self-harm, violence, or severe crisis.

### Sequence
1. Stop ordinary PK-15 flow.
2. Activate CP-01.
3. Prioritize real-world safety action.
4. Return to relational work only after immediate safety is reasonably addressed.

---

## Cross-pattern principles
- One consequential question at a time.
- Do not infer identity/diagnosis from one disclosure.
- Do not confuse understanding with agreement.
- Do not force total resolution in the first conversation.
- Sensitive topic ≠ automatic crisis.
- Safety risk ≠ ordinary coaching problem.
